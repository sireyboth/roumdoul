# Invitation props

Shared, reusable photo props for invitation templates (River Love's letter section uses them).
Kept out of `images/invitations/{template}/`, because the `/demo/...` page treats every image in that
folder as a customer photo.

Only add files we are allowed to use **commercially** (CC0, public domain, or a licence we bought).
